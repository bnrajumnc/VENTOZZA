# VENTOZZA homepage

React + TypeScript homepage concept, built with Vite. The visual direction takes broad inspiration from Invoke Tiles’ rotating hero, product sizes, and tile gallery, while using VENTOZZA branding and original copy.

## Run locally

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite. Create a production build with `npm run build`.

The homepage includes a rotating hero, responsive navigation, animated tile product cards, tile sizes, an about section, tile documentation prompts, and an enquiry form. Product names, finishes and sizes are sample content; replace them with VENTOZZA's verified catalogue before launch. Tile photos load from Pexels (`TXTR`, `cottonbro studio`, `David Underland`, and `RDNE Stock project`) and fonts load from Google Fonts. The form currently shows a local confirmation message; connect it to a mail or CRM service before using it for enquiries.
